# 数据库配置指南

## 📋 前置要求

- ✅ MySQL 8.0+ 已安装（你已安装 8.0.34）
- ✅ MySQL 服务正在运行
- ✅ 知道 root 用户密码

## 🔧 配置方法

### 方法1：使用批处理脚本（最简单）

1. **双击运行**：`后端API/init-database.bat`
2. **输入密码**：根据提示输入 MySQL root 密码
3. **等待完成**：看到 "✅ 数据库初始化成功！" 即可

### 方法2：使用 PowerShell 命令

打开 PowerShell，执行：

```powershell
# 进入项目根目录
cd "C:\Users\刘刘\Desktop\小程序商城"

# 执行数据库脚本（会提示输入密码）
mysql -u root -p < database.sql
```

### 方法3：使用 MySQL Workbench（可视化）

1. **打开 MySQL Workbench**
2. **连接到本地 MySQL** (localhost:3306)
3. **点击菜单**：File → Open SQL Script
4. **选择文件**：`database.sql`
5. **点击执行**：点击闪电图标 ⚡
6. **等待完成**：看到 "XX rows affected" 消息

### 方法4：使用 Navicat / phpMyAdmin

1. 打开你的数据库管理工具
2. 连接到 MySQL
3. 导入 `database.sql` 文件
4. 执行脚本

## ✅ 验证数据库

执行以下命令验证数据库是否创建成功：

```sql
-- 查看数据库
SHOW DATABASES LIKE 'snack_mall';

-- 使用数据库
USE snack_mall;

-- 查看所有表
SHOW TABLES;

-- 应该看到 15 张表：
-- users, addresses, categories, products, carts
-- orders, order_items, coupons, user_coupons
-- points_logs, banners, reviews, admins, payment_logs, delivery_logs
```

## 🔑 配置后端连接

数据库创建成功后，修改 `后端API/.env` 文件：

```env
# 数据库配置
DB_HOST=localhost
DB_PORT=3306
DB_NAME=snack_mall
DB_USER=root
DB_PASSWORD=你的实际密码
```

⚠️ **重要**：将 `你的实际密码` 替换为你的 MySQL root 密码

## 🐛 常见问题

### 1. Access denied for user 'root'

**原因**：密码错误
**解决**：
```powershell
# 重置 MySQL root 密码
mysql -u root -p
# 输入当前密码后执行：
ALTER USER 'root'@'localhost' IDENTIFIED BY '新密码';
FLUSH PRIVILEGES;
```

### 2. Can't connect to MySQL server

**原因**：MySQL 服务未启动
**解决**：
```powershell
# 启动 MySQL 服务
net start MySQL80
```

### 3. Unknown database 'snack_mall'

**原因**：数据库脚本未执行成功
**解决**：手动创建数据库
```sql
CREATE DATABASE snack_mall DEFAULT CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
```

### 4. Table already exists

**原因**：数据库表已存在
**解决**：
```sql
-- 删除数据库重新创建（⚠️ 会丢失数据）
DROP DATABASE snack_mall;
-- 然后重新执行初始化脚本
```
