## 📱 常见问题

### Q1: 显示"加载中"一直转圈
**原因**: 后端未启动或API地址错误

**解决**:
1. 启动后端服务
2. 检查 `app.js` 中的 `apiBase` 配置

---

### Q2: 显示"网络错误"
**原因**: 
- 后端服务未启动
- 端口被占用
- 防火墙阻止

**解决**:
```bash
# 检查3000端口是否被占用
netstat -ano | findstr :3000

# 如果被占用，杀死进程
taskkill /PID <进程ID> /F

# 重新启动后端
cd 后端API
npm start
```

---

### Q3: 控制台显示401错误
**原因**: 登录认证失败

**解决**: 
首页不需要登录，检查代码中的 `needAuth` 参数：
```javascript
// 正确写法（第三个参数为false）
api.get('/products', {}, false)

// 错误写法（会要求登录）
api.get('/products', {}, true)
```

---

### Q4: 图片不显示
**原因**: 
- 图片URL错误
- 网络问题
- 图片服务器限制

**临时解决**: 使用占位图
```
https://img.yzcdn.cn/vant/cat.jpeg
```
