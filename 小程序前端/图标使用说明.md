# TabBar 图标使用说明

## 🎨 图标获取方式

### 推荐图标库
1. **iconfont.cn（阿里巴巴图标库）**
   - 网址: https://www.iconfont.cn/
   - 优点: 免费、图标丰富、支持下载PNG/SVG

2. **IconPark（字节跳动图标库）**
   - 网址: https://iconpark.oceanengine.com/
   - 优点: 风格统一、开源免费

3. **Remix Icon**
   - 网址: https://remixicon.com/
   - 优点: 简洁现代、开源

## 📏 图标规范

### 尺寸要求
- **默认状态**: 81x81px（2x图）或 162x162px（3x图）
- **选中状态**: 同上
- **格式**: PNG（推荐）或 JPG
- **背景**: 透明

### 命名规范
```
/images/
├── icon-home.png          # 首页-默认
├── icon-home-active.png   # 首页-选中
├── icon-category.png      # 分类-默认
```

## 📝 使用步骤

### 1. 在 iconfont.cn 下载图标

1. 访问 https://www.iconfont.cn/
2. 搜索关键词（如"首页"）
3. 选择喜欢的图标，加入购物车
4. 点击购物车图标，选择"下载代码"
5. 选择 PNG 格式，尺寸选择 128px 或 256px
6. 下载并解压

### 2. 处理图标

#### 方式一：在线处理
- 使用 https://www.iloveimg.com/zh-cn/resize-image/resize-png
- 调整尺寸为 81x81px 或 162x162px
- 保存为透明背景

#### 方式二：使用PS/Figma
- 创建画布：81x81px 或 162x162px
- 导入图标，居中对齐
- 导出为 PNG（透明背景）

### 3. 修改配色

**默认状态**（灰色）：
- 推荐色值: #999999 或 #666666

**选中状态**（主题色）：
- 推荐色值: #ff6b35（当前项目主色）

可以使用在线工具修改颜色：
- https://www.iloveimg.com/ (调整亮度/对比度)
- 或使用PS的色相/饱和度调整

### 4. 放入项目

将处理好的图标放入 `images/` 目录：
```
小程序前端/images/
├── icon-home.png
├── icon-home-active.png
├── icon-category.png
├── icon-category-active.png
├── icon-cart.png
├── icon-cart-active.png
├── icon-user.png
└── icon-user-active.png
```

### 5. 更新 app.json

图标路径已在 `app.json` 中配置好，只需替换图标文件即可：

```json
{
  "tabBar": {
    "list": [
      {
        "pagePath": "pages/index/index",
        "text": "首页",
        "iconPath": "images/icon-home.png",
        "selectedIconPath": "images/icon-home-active.png"
      },
      {
        "pagePath": "pages/category/category",
        "text": "分类",
        "iconPath": "images/icon-category.png",
        "selectedIconPath": "images/icon-category-active.png"
      },
      {
        "pagePath": "pages/cart/cart",
        "text": "购物车",
        "iconPath": "images/icon-cart.png",
        "selectedIconPath": "images/icon-cart-active.png"
      },
      {
        "pagePath": "pages/user/user",
        "text": "我的",
        "iconPath": "images/icon-user.png",
        "selectedIconPath": "images/icon-user-active.png"
      }
    ]
  }
}
```

## ⚠️ 注意事项

1. **图标大小**: 确保图标不要太大（< 50KB/个），影响加载速度

2. **风格统一**: 4个TabBar图标风格要统一（线性或面性）

3. **清晰度**: 建议使用 162x162px（3x图），在高分辨率设备上更清晰

4. **版权**: 使用iconfont时注意查看图标授权，商业项目建议购买授权或使用免费商用图标

5. **颜色**: 默认状态用灰色系，选中状态用品牌色，保持视觉层次

6. **测试**: 在真机上测试图标显示效果，确保清晰度
