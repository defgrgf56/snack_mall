# 小程序主页没有数据 - 排查指南

## 可能原因及解决方案

### 1. 后端服务未启动

**现象：**
- 页面空白，没有任何数据
- 控制台显示网络连接失败

**解决方案：**
```bash
# 进入后端目录
cd "后端API"

# 启动后端服务
npm run dev

# 或使用一键启动脚本
双击 "一键启动后端.bat"
```

**验证：**
浏览器访问 `http://localhost:3000/api` 应该能看到：
```json
{
  "code": 200,
  "message": "API is running",
  "data": {
    "version": "1.0.0",
    "timestamp": "..."
  }
}
```

### 2. 数据库没有数据

**现象：**
- 接口请求成功，但返回空数组
- 分类、商品、轮播图都是空的

**解决方案：**
```bash
# 进入后端目录
cd "后端API"

# 运行数据迁移脚本
node migrations/run-all.js

# 或手动执行 SQL
# 使用 MySQL 客户端导入 database.sql 文件
```

### 3. 小程序未勾选"不校验合法域名"

**现象：**
- 控制台显示 "request:fail url not in domain list"
- 请求被微信拦截

**解决方案：**
1. 打开微信开发者工具
2. 右上角"详情"按钮
3. 本地设置 → 勾选"不校验合法域名、web-view（业务域名）、TLS 版本以及 HTTPS 证书"

### 4. 端口冲突

**现象：**
- 后端启动失败
- 提示端口 3000 已被占用

**解决方案：**
```bash
# Windows 查看占用端口的进程
netstat -ano | findstr :3000

# 关闭占用端口的进程（以管理员身份运行）
taskkill /PID <进程ID> /F

# 或修改后端端口（后端API/.env 文件）
PORT=3001
```

### 5. 网络请求配置问题

**检查配置文件：**
```javascript
// 小程序前端/config/env.js
API_BASE_URL: 'http://localhost:3000/api'  // 确保地址正确
```

### 6. 使用测试页面诊断

访问小程序的 **API测试页**（test-api）:
1. 在小程序中导航到 API测试页
2. 点击"运行所有测试"
3. 查看每个接口的返回结果
4. 根据错误信息定位问题

## 调试步骤

### 步骤 1：检查后端服务
```bash
# 访问后端根路径
curl http://localhost:3000/api

# 或浏览器访问
http://localhost:3000/api
```

### 步骤 2：测试单个接口
```bash
# 测试轮播图接口
curl http://localhost:3000/api/banners

# 测试分类接口
curl http://localhost:3000/api/categories

# 测试商品接口
curl http://localhost:3000/api/products
```

### 步骤 3：查看控制台日志

**小程序控制台：**
- 打开微信开发者工具
- 点击"控制台"标签
- 查看红色错误信息

**后端控制台：**
- 查看后端启动的终端
- 观察请求日志和错误信息

### 步骤 4：检查数据库

```sql
-- 检查轮播图数据
SELECT * FROM banners WHERE status = 1;

-- 检查分类数据
SELECT * FROM categories WHERE status = 1;

-- 检查商品数据
SELECT * FROM products WHERE status = 1 LIMIT 10;
```

## 常见错误信息

### "未登录" 或 "Token 失效"
- 某些接口需要登录，但用户未登录
- 解决：先使用 API测试页的"开发快速登录"功能

### "网络连接失败"
- 后端服务未启动
- 端口配置错误
- 防火墙拦截

### "请求超时"
- 数据库查询慢
- 数据量太大
- 服务器性能问题

### "数据为空"
- 数据库没有初始化数据
- SQL 查询条件不匹配（如 status = 1 但数据库中 status = 0）

## 快速修复

如果你刚克隆项目，按以下顺序操作：

```bash
# 1. 安装依赖
cd 后端API
npm install

# 2. 配置数据库（复制 .env.example 为 .env 并配置）
cp .env.example .env
# 编辑 .env 文件，设置数据库连接信息

# 3. 创建数据库
mysql -u root -p
CREATE DATABASE mall_db CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
exit;

# 4. 导入数据
mysql -u root -p mall_db < database.sql

# 5. 运行迁移（如果有）
node migrations/run-all.js

# 6. 启动后端
npm run dev
```

## 检查清单

- [ ] 后端服务已启动（访问 http://localhost:3000/api 有响应）
- [ ] 数据库已创建并导入数据
- [ ] 小程序已勾选"不校验合法域名"
- [ ] API 地址配置正确（http://localhost:3000/api）
- [ ] 数据库中有测试数据（轮播图、分类、商品）
- [ ] 使用 API测试页验证接口正常
