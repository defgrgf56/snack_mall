# 电商小程序 TabBar 设计方案

## 📊 竞品分析

### 主流电商小程序TabBar对比

| 小程序 | Tab数量 | 配置 |
|--------|---------|------|
| 京东 | 5个 | 首页、分类、发现、购物车、我的 |
| 淘宝 | 5个 | 首页、微淘、消息、购物车、我的淘宝 |
| 拼多多 | 5个 | 首页、聊天、视频、个人中心、多多买菜 |
| 唯品会 | 4个 | 首页、分类、购物车、个人中心 |
| 有赞商城 | 4个 | 首页、分类、购物车、我的 |

**结论**: 电商小程序通常使用**4-5个Tab**

---

## 🎯 推荐方案

### 方案一：经典4个Tab（✅ 推荐）

```
┌─────────┬─────────┬─────────┬─────────┐
│  🏠首页  │ 📋分类  │ 🛒购物车 │ 👤我的  │
└─────────┴─────────┴─────────┴─────────┘
```

**配置**:
1. **首页** - 展示轮播图、分类、热门商品
2. **分类** - 商品分类浏览
3. **购物车** - 购物车管理
4. **我的** - 个人中心、订单、设置

**优点**:
- ✅ 结构清晰，用户认知成本低
- ✅ 符合用户购物习惯
- ✅ Tab数量适中，不拥挤
- ✅ 覆盖核心功能

**适用场景**: 
- 中小型商城
- 零食、食品类电商
- 垂直品类电商

## 🎨 当前项目建议

### 推荐配置：方案一（4个Tab）

**理由**:
1. 项目定位：零食商城，属于垂直品类电商
2. 功能完整：已有首页、分类、购物车、个人中心页面
3. 用户习惯：符合传统电商使用习惯
4. 简洁高效：功能覆盖全面，不冗余

---

## 📋 详细配置

### 1. 首页 (Home)
- **路径**: `pages/index/index`
- **图标**: 🏠 房子图标
- **功能**:
  - 轮播图广告
  - 商品分类导航
  - 优惠券展示
  - 热门商品推荐
  - 新品上市
  - 搜索入口

### 2. 分类 (Category)
- **路径**: `pages/category/category`
- **图标**: 📋 分类/列表图标
- **功能**:
  - 左侧分类列表
  - 右侧商品展示
  - 快速筛选
  - 分类搜索

### 3. 购物车 (Cart)
- **路径**: `pages/cart/cart`
- **图标**: 🛒 购物车图标
- **功能**:
  - 购物车列表
  - 商品数量调整
  - 多选/全选
  - 优惠券选择
  - 结算功能
  - **徽标**: 显示购物车商品数量

### 4. 我的 (User)
- **路径**: `pages/user/user`
- **图标**: 👤 用户头像图标
- **功能**:
  - 用户信息
  - 订单列表（待付款、待发货、待收货、待评价）
  - 收货地址管理
  - 优惠券管理
  - 积分中心
  - 收藏夹
  - 客服/设置

## 🎨 设计规范

### 图标尺寸
- **默认状态**: 81x81px（2x） 或 162x162px（3x）
- **选中状态**: 81x81px（2x） 或 162x162px（3x）
- **格式**: PNG（推荐透明背景）

### 配色方案
- **默认颜色**: #999999 或 #666666（灰色）
- **选中颜色**: #FF6B00（橙色，当前项目主色）
- **背景颜色**: #FFFFFF（白色）
- **边框**: #EEEEEE（浅灰）

### 文字
- **字号**: 20rpx（10pt）
- **默认颜色**: #999999
- **选中颜色**: #FF6B00

## 💡 实现建议

### 购物车徽标
在 `app.js` 中动态更新购物车数量：
```javascript
// 更新购物车数量徽标
updateCartCount() {
  if (this.globalData.cartCount > 0) {
    wx.setTabBarBadge({
      index: 2,  // 购物车Tab索引
      text: String(this.globalData.cartCount)
    })
  } else {
    wx.removeTabBarBadge({
      index: 2
    })
  }
}
```

### 消息提醒
如果需要，可以在"我的"Tab显示未读消息：
```javascript
wx.setTabBarBadge({
  index: 3,  // 我的Tab索引
  text: '3'  // 未读消息数
})
```

## 🚫 不推荐的Tab

### ❌ 搜索Tab
- **原因**: 搜索是辅助功能，不需要独立Tab
- **替代**: 在首页顶部放置搜索框
- **参考**: 京东、淘宝都是顶部搜索框

### ❌ 消息Tab
- **原因**: 零食商城不需要高频消息
- **替代**: 在"我的"页面放置消息入口
- **例外**: 如果有直播/社区功能，可以考虑

### ❌ 会员Tab
- **原因**: 会员功能不是高频功能
- **替代**: 在"我的"页面放置会员中心入口

---

## 📱 微信小程序TabBar限制

### 官方限制
- **数量**: 最少2个，最多5个
- **图标**: 必须是本地图片路径，不支持网络图片
- **大小**: 图标文件建议40KB以内
- **文字**: 最多4个汉字

### 最佳实践
- ✅ 使用4-5个Tab
- ✅ 图标风格统一
- ✅ 文字简洁明了
- ✅ 选中状态明显
- ✅ 颜色符合品牌调性
