# TabBar 图标准备说明

## 需要的图标

在 `images/tabbar/` 目录下需要准备以下8个图标文件：

### 1. 首页图标
- `home.png` - 首页未选中（灰色）
- `home-active.png` - 首页选中（橙色 #FF6B00）

### 2. 分类图标
- `category.png` - 分类未选中（灰色）
- `category-active.png` - 分类选中（橙色）

### 3. 购物车图标
- `cart.png` - 购物车未选中（灰色）
- `cart-active.png` - 购物车选中（橙色）

### 4. 我的图标
- `user.png` - 我的未选中（灰色）
- `user-active.png` - 我的选中（橙色）

## 图标规格

- **尺寸**: 81px × 81px（推荐）
- **格式**: PNG
- **背景**: 透明
- **颜色**: 
  - 未选中：#999999（灰色）
  - 选中：#FF6B00（橙色）

## 图标获取方式

### 方式一：使用 iconfont
1. 访问 https://www.iconfont.cn/
2. 搜索关键词：home, category, cart, user
3. 下载 PNG 格式
4. 调整颜色和尺寸

### 方式二：使用在线工具
1. 访问 https://www.flaticon.com/
2. 搜索并下载图标
3. 使用在线工具调整颜色

### 方式三：自己设计
使用 Figma、Sketch 或 PhotoShop 设计

## 快速测试用占位图标

如果暂时没有图标，可以：
1. 创建 81x81 的纯色图片作为占位
2. 使用简单的文字图标
3. 或者先不使用 tabBar（当前方案）

## 添加图标后

1. 将图标文件放到 `images/tabbar/` 目录
2. 在 `app.json` 中恢复 tabBar 配置
3. 重新编译小程序

## 示例 tabBar 配置

```json
"tabBar": {
  "color": "#999999",
  "selectedColor": "#FF6B00",
  "backgroundColor": "#ffffff",
  "borderStyle": "black",
  "list": [
    {
      "pagePath": "pages/index/index",
      "text": "首页",
      "iconPath": "images/tabbar/home.png",
      "selectedIconPath": "images/tabbar/home-active.png"
    },
    {
      "pagePath": "pages/category/category",
      "text": "分类",
      "iconPath": "images/tabbar/category.png",
      "selectedIconPath": "images/tabbar/category-active.png"
    },
    {
      "pagePath": "pages/cart/cart",
      "text": "购物车",
      "iconPath": "images/tabbar/cart.png",
      "selectedIconPath": "images/tabbar/cart-active.png"
    },
    {
      "pagePath": "pages/user/user",
      "text": "我的",
      "iconPath": "images/tabbar/user.png",
      "selectedIconPath": "images/tabbar/user-active.png"
    }
  ]
}
```
